# Scrubby privacy policy

*Effective 22 October 2026*

Scrubby ("Scrubby: image & video viewer for GitHub PRs") is a Chrome extension that shows images from GitHub pull requests in an in-page viewer and adds playback controls to pull request videos.

## Data Scrubby collects

None. Scrubby does not collect, store, sell or share any personal information or browsing data.

- **No accounts and no tracking.** There are no analytics, cookies or identifiers, and no third-party services.
- **No storage.** Scrubby saves nothing in your browser or anywhere else. Settings such as playback speed last only while the page is open.
- **No data leaves your browser.** Scrubby reads the images and videos already on the GitHub page so it can display them, and that happens entirely on your device.

## Network requests

Scrubby only loads images and videos that are already part of the GitHub page you're viewing, from GitHub's own servers. If a pull request video's temporary link has expired, Scrubby asks GitHub for a fresh link to the same file. It makes no other network requests.

## Permissions

Scrubby requests no browser permissions. Its only access is a content script that runs on `https://github.com/*` pages.

## Changes

If this policy changes, the new version will be published at this address with a new effective date.
